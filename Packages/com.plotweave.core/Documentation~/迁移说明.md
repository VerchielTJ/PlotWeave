# PlotWeave迁移候选版

原主制作/数据/播放链已按功能迁移，详细证据位于工程根目录Doc。UPM包提供独立类型与行模型、UGUI制作、双端契约生成、原布局Excel交换、共享播放Core及宿主和独立JSON事件载体。

Runtime/Authoring负责动态类型、表头、行、文本、通用表与工作区；Runtime/AuthoringUI在UNITY_EDITOR下提供制作控件和会话；Runtime/DataContracts提供共同读取口；Runtime/Playback包含Core、六项服务、Factory、参考View、游戏Host及独立播放数据；Runtime/Legacy保存独立JSON数据，不包含原主链也未实现的执行器。

最终129项EditMode通过。新播放场景Windows构建与三路径真实Play Mode截图见根目录Doc/Records。未验证原Luban配置、IL2CPP及移动平台；TMP专有表现、原游戏业务与原未实现演出语义不计为完成。

最初PlotDocument/GraphView/PlotSession和七表工作簿保留为独立原型，不能与新UGUI工具及六表原布局混为一套格式。历史15项原型验证保留为历史，当前迁移以Doc阶段记录为准。

原工程只读，演示资产与美术均为新建。当前未公开发布或选择开源许可证。
