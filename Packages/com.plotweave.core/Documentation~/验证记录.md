## 手动体验入口

1. Unity 菜单 `Tools / PlotWeave / 历史原型 / 打开GraphView编辑器`，选择 `Assets/PlotWeaveDemo/Example.asset`。
2. 查看节点、Next 和选项连线；选择节点检查右侧字段；点击“预览”，体验两条分支。
3. 打开 `Assets/PlotWeaveDemo/DemoAsset.unity` 进入 Play Mode；再打开 `DemoCompiled.unity` 对照编表后的播放行为。
4. 尝试导出工作簿、修改对白、编译 JSON，确认编表工作流符合实际使用习惯。
