# PlotWeave 迁移档案

这里是原剧情编辑器迁移工作的统一档案入口。按功能批次记录源模块、目标实现、行为差异、测试证据和剩余事项。测试通过只证明被测范围，不代表完整迁移完成。

这是历史迁移档案。公开版首次体验请从[公开版首次运行](公开版首次运行.md)开始；原项目数据、美术及原布局截图不分发。历史测试和构建记录不替代[公开克隆检查](Records/PublicExport/verification.json)，较早文档中的“未发布／许可证未定”描述保留当时语境；当前项目采用根目录MIT许可证。

评审从[离线交互类图](Review/index.html)开始；查看[来源与状态说明](Review/设计来源与状态说明.md)区分原设计和本次补齐。AI可从根目录[工程上下文](../AI_CONTEXT.md)和`Tools/Review/query.py`进入同一份结构索引。

公开体验入口：执行 `Tools / PlotWeave / 迁移样例 / 创建公开合成章节与奖励样例`，打开 `Assets/PlotWeaveMigration/Stage18_CampaignReference/CampaignReference.unity` 并Play。Stage18用新合成内容展示主线/日常、分支、首次奖励与重看、日期/区域锁、跳过确认与取消；默认内存进度，跨次保存可在 `PlotLegacyCampaignHost` 启用 `persistProgress`，通过 `saveFile` 写到 `Application.persistentDataPath`。操作步骤见[快速上手](快速上手.md)。

`Tools / PlotWeave / 本地原布局` 下的四个打开菜单读取本机迁移记录和 `Assets/PlotWeaveLocal` 场景；公开合成Stage18可独立生成，不依赖本机原剧情、美术或布局。
