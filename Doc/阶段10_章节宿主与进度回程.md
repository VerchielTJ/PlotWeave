# 阶段10：章节宿主、进度与回程

日期：2026-10-28。将原游戏主线/日常章节职责迁成可替换接口，并提供离线可运行示例；没有连接原游戏服务器。

`IPlotChapterBackend`负责LoadAsync与CompleteAsync；`IPlotChapterPlayer`适配共享播放Core；`IPlotChapterNavigation`负责进入、返回和错误呈现。PlotChapterSession控制Loading/Playing/Reporting/ReportFailed/Completed/Cancelled等状态。

播放完成只申领一次结算。后端可用RequiresCompletionReport标记已确认章节的重播；该路径直接回程，不重复结算或显示首次完成。收到确认后才返回UI和显示新完成标记；失败可重试，沿用同一CompletionID，后端须用该ID实现幂等。关闭播放按取消处理，不上报完成。新会话、取消和Dispose隔离旧加载/结算的迟到结果。Player错误回程一次，不上报成功。

`PlotLocalChapterBackend`按Main/Daily和章节ID分别保存进度与回执；存档先写临时文件再替换，保存失败不提交内存进度。它仅是离线示例，正式服务器接入实现上述后端接口。

入口：`Tools / PlotWeave / 迁移样例 / 创建主线与日常章节宿主`；场景`Assets/PlotWeaveMigration/Stage10_Chapters/ChapterHost.unity`。主线和日常均走分支演出，再确认完成、返回菜单。示例进度写入Application.persistentDataPath下独立JSON，不写回剧情资产。

测试覆盖确认前不回程、重复完成、失败重试、取消加载、关闭、迟到结算、播放错误、释放和持久化回执。真实Play Mode验证两类章节均能播放、结算并返回；具体记录见Records/Stage10。
