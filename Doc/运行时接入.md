# 运行时接入

## 数据和共享播放器

`PlotPlayerHost`是参考宿主；将项目资源Key绑定到sprites、actorPrefabs、audioBindings、effects和emotions。配置完成后：

```csharp
host.Initialize(document, PlotPlayerRuntimeMode.GameRuntime);
host.Play(entryNode);
host.Core.SignalReceived += (name, payload) => HandleSignal(name, payload);
```

手动驱动其他宿主时，对同一Core调用Tick，避免与Host.Update重复推进。分支由Core.Choices提供，调用Choose(index)；暂停期间不接受选择。Core是一次会话的状态机，重新Open会清空变量；章节间共享变量应由宿主保存。

`IPlotPlayerView`、`IPlotBranchView`、`IPlotEventPresentation`和`IPlotPausableView`分别负责基础呈现、选项、事件表现及暂停。自定义表现层可以按需实现；未知事件不会被当成成功跳过。

## 事件

工作区eventTracks绑定PlotNodeEventTrackAsset。每个track.nodeID对应真实节点；executionOrder=-1按列表顺序执行，其他值为回调ID。

```csharp
var move = new PlotEventJsonData("actor.move") {
    parameters = new List<string> { "101", "2", ".5", "Smooth" },
    callbackList = "1"
};
var notify = new PlotEventJsonData("signal", 1) {
    parameters = new List<string> { "actor.arrived", "101" }
};
```

将两项放在同一节点的events中。原表RoleName等资源枚举需先映射到当前演员ID和资源Key。回调仅在操作完成后执行；它不是按executionOrder全局排序。

注册项目事件：

```csharp
host.Core.EventRegistry.Register("project.wait", (data, context) =>
    new PlotTweenOperation(context.Number(data, 0)));
```

自定义异步事件返回IPlotOperation。Tick推进，IsCompleted表示可进入回调，Dispose必须可重复调用并清理在途工作；不要让取消后的资源回调修改新节点。

## Luban

游戏已有Tables/ByteBuf时，从解码后的DataList构造播放文档：

```csharp
var document = PlotLubanTableReader.Read(
    tables.TbPlotAtom.DataList, tables.TbActor.DataList,
    tables.TbDialog.DataList, tables.TbConstant.DataList,
    row => new GamePlotAtomDataAdapter(row));
```

GamePlotAtomDataAdapter来自本工作区的双端生成配置，命名空间取决于配置。Luban文本列KeyID/SimpleChinese等先归一为共同key/value结构；读取器为原五语言形状提供该转换。其他表结构可直接实现IPlotValueSource。

新增轨道单独加载：`PlotLubanTableReader.ApplyEventSidecar(document, json)`。它会先检查所有节点与回调，再整体提交。核心包不依赖Luban.dll，也不会在Player调用编表进程。

## 章节

实现IPlotChapterBackend和IPlotChapterNavigation，用PlotChapterHostPlayer连接现有Host：

```csharp
var player = new PlotChapterHostPlayer(host);
var session = new PlotChapterSession(backend, player, navigation);
await session.StartAsync(new PlotChapterRequest(PlotChapterKind.Main, "chapter-01"));
```

LoadAsync返回PlotChapterContent，包含独立快照、入口和RequiresCompletionReport。新章节需要结算确认，已确认重播可将该标记设false。CompleteAsync必须按CompletionID实现幂等；重试沿用同一ID。失败时UI可调用RetryReportAsync，退出调用Cancel，销毁时Dispose会解除回调。

Daily章节的周期、解锁、奖励、账号和服务器日期由业务后端决定，核心按Kind+ChapterID寻址；离线示例只演示两类章节的独立进度。

移动端和IL2CPP需在目标工程验证，反射对象后端需关注裁剪；需要完全显式访问时实现IPlotValueSource。强类型Luban播放场景展示了不在Player内反射Tables的读取路径。
