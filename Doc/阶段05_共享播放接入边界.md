# 阶段05：共享播放接入边界

日期：2026-10-28。状态：本批实现、124项联测、三路径真实运行与新播放场景构建验收完成，已归档。

## 原系统基线

真正的 `IPlotPlayer` 与 `PlotPlayerCore` 在 `HotUpdate/UI/PlotPlayerUI/PlotPlayerUI_NodeClass.cs`。`IPlotPlayer.cs` 文件主要容纳配置、数据提供者、加载器、池、文本处理器、运行环境和Factory。两个宿主 `EditorPlotPlayerUI` 与 `PlotPlayerUI` 都创建同一Core，并注入这六项服务。

Core负责 Init/Open/Close、按ID加载、点击补全打字/下一节点、自动播放、暂停恢复、跳转、幕布及加载/错误/结束事件。表现分为对话框、幕布、坐标、背景、角色剧院。角色剧院按本节点RoleAction集合保留/退场/入场并更新位置。数据中的动作和表情原实现留空；Branch虽在契约中存在，Core未消费，不应声称迁移了已经完成的分支播放。

游戏宿主中的主线/日常章节选择、新章节状态、网络结算和返回UI是游戏业务边界，需要宿主回调接入，不能携带原游戏协议与全局单例进入工具包。

## 本批实施约束

- 两个宿主必须调用同一个Core，不另写一套“看起来能播放”的编辑预览状态机。
- 动态作者数据、已生成适配器和编译对象通过共同值读取口转换播放所需字段，不能重新绑定cfg Bean。
- 运行环境、语言、池与数据缓存按播放器实例隔离，不使用全局模式开关。
- 关闭/跳转/重载后取消旧表现请求；迟到的资源回调不能覆盖当前节点。
- 自动播放只在文本、角色与背景均完成后启动一次延时；暂停冻结推进，结束只发一次。
- 预览从制作面板当前节点启动，先处理未保存修改；刷新重建数据快照。
- 原未实现的Branch、动作/表情和旧JSON回调另列，不与本批核心迁移混算。

## 实现对应

- `Runtime/Playback/PlotPlayerCore.cs`：IPlotPlayer、生命周期、点击/自动/暂停/跳转、幕布与三类事件，Factory保留六项创建职责。使用显式Tick与请求epoch替代散落协程，避免多次启动自动推进或旧回调越过关闭/跳转边界。
- `PlotPlayerServices.cs`：按实例隔离的数据字典缓存、资源加载、对象池、文本处理、运行环境与配置；数据注入先校验再替换，读取返回副本。两类文本相同KEY不串表，语言索引保持原次序。
- `PlotPlaybackData.cs`：播放所需7列与角色/背景/分支结构，不引用cfg；接受作者IPlotValueSource、实际生成的Editor/Game适配器和公开字段/属性对象。完整动态作者接口仍由阶段02生成器负责，播放Core仅消费已有播放语义所需字段。
- `PlotPlayerView.cs`：对话、幕布、位置、背景、角色剧院的独立UGUI参考实现。角色按当前集合进出场，池复用、迟到Sprite回调隔离；多个背景声明只有最后一项能更新最终背景。
- `PlotPlayerHost.cs`：游戏运行宿主，读取独立播放Asset或JSON；`Completed`事件接游戏章节结算、返回UI等业务。
- `Editor/Playback/EditorPlotPlayerUI.cs`：制作面板宿主，按钮先处理未保存修改，每次预览重新编译快照，再装配同一个Host/Core。
- `PlotPlaybackCompiler.cs`：作者数据编译为不携带表头、编辑器和AssetDatabase引用的播放Asset/JSON。

## 场景与入口

先创建样例：`Tools / PlotWeave / 迁移样例 / 创建共享播放与双宿主样例`。

- 制作预览：`Assets/PlotWeaveMigration/Stage05_Playback/EditorPlayback.unity`，Play后点击“从此节点预览”。
- 资产播放：同目录 `GamePlayback.unity`。
- JSON播放：同目录 `JsonPlayback.unity`。
- 自有工作区可在Inspector设置 `visuals` 资源绑定，并用“编译所选工作区播放数据”生成新的播放Asset及JSON。

样例背景和人物剪影为新生成的演示资源。实际游戏资源通过catalog或自定义IPlotResourceLoader接入。参考界面含补全/继续、自动、暂停/恢复和关闭按钮。需要更新预览数据时关闭播放再点击制作面板预览，会重新建立快照。

## 行为差异与边界

与原版一致，手动推进可中断未完成的资源表现；自动推进等待文本、背景、角色和幕布就绪。暂停冻结核心与表现Tick。关闭、跳转取消旧请求，无法实际中止的资源加载结果也不能写回旧画面。修正原版自动播放多协程重复推进的可能性；结束事件只触发一次。

五语言、转义、默认逐字速度及自动延时保留。参考UGUI使用普通Text并按Unicode文字单元打字；原TMP特有富文本、内联图标需通过IPlotPlayerView接入，不宣称完全视觉兼容。场景坐标以配置数组注入，不携带原预制体中的固定层级与坐标。

Branch保留在数据中，本Core遵循原Next行为，不自动提供原版不存在的选项调度。动作/表情通过 `ActorActionRequested` 交给游戏表现层；默认层不把位置更新称为已经实现动作动画。SetType字段保留，参考层按资源切换背景，未伪造原版没有实现的过渡算法。

游戏专属网络协议、章节状态和全局UI不进入包。IL2CPP、Android/iOS与原Luban工程均尚未运行；Windows构建不能代替这些验证。
