# 快速上手

## 体验迁移后的编辑器

1. `Tools / PlotWeave / 打开剧情编辑器`自动打开制作场景、进入Play Mode并显示Game视图，无需再手动点Play。已有本地迁移记录与原制作场景时，优先使用原独立制作界面；公开克隆缺少这些本地内容时，使用通用UGUI制作页。已有可用制作会话时，主入口只聚焦Game视图。
2. 在Game视图中载入并选择节点。在原布局中，右侧与底部用于节点、标量、枚举、列表Bean、KEY及五语言文本输入，左上是内嵌试跑区；对白输入框停靠在试跑区下方，制作输入与播放对白可同时查看。
3. 输入先进入工作副本。无需保存即可试跑：原布局的起始节点框可填写正整数节点ID，留空则使用当前节点，然后点播放；通用制作页点“试跑当前输入”。预览取最新工作副本，不写回资产。
4. 在原布局中继续改参数或文本，再点“刷新播放数据”。活动预览会从当前播放节点重新试跑最新输入，并保留自动播放与暂停状态；已关闭的预览仍保持关闭。需要换起点时重新填写起始节点并点播放。
5. 确认输入后点“保存全部”或相应保存按钮写回资产。切节点仍有保存/放弃/取消选择；试跑不会替代保存。
6. 原布局顶部点“当前工作区表格互转”，通用制作页点“表格互转”，打开绑定当前工作区的交换窗口。导出或导入前按提示处理尚未保存的输入，取消则不继续交换。

顶部“站位参考”用于开关原位置标尺，默认关闭；标尺位于预览内，不拦截播放器点击。试跑画面按播放器原设计尺寸等比缩放，窗口比例不同可能留边，避免固定坐标的对白、演员及按钮被拉伸或挤出画面。

制作窗口策略下限为1024×600；本轮已测1920×1080、1280×720、1092×905、1024×768并通过支持范围检查。900×600与720×900仍有密度不足，界面会提示扩大或最大化Game视图，这两个尺寸不计作支持通过。

仅查看场景结构时，可使用“本地原布局 / 打开制作界面”或“制作工具 / 打开UGUI制作场景”。这些静态菜单只打开场景并显示一次启动窗口；点“进入剧情制作（Play）”才会初始化输入工具。直接双击场景资产也只是EditMode预览。正在运行其他场景时，主入口会提示先退出Play Mode；取消当前场景保存/切换时不会自动启动。

原制作宿主初始化失败时会清理工作副本与预览回调，并显示只读失败提示；请检查Console，修复后退出并重新进入制作。不要把缺失工具栏或尚未初始化的静态画面当作可录入界面。启动和多尺寸检查范围见[阶段20](阶段20_启动与多尺寸适配.md)。

未保存草稿具有恢复入口，但草稿冲突检测尚有已知风险。退出Play Mode前建议显式保存；恢复旧草稿前先核对节点及共享文本表是否已被其他操作更新，不应把自动备份视为无冲突的版本合并。见[设计审查与开放问题](Review/设计审查_2026-10-29.md)。本轮制作闭环的变更和验收状态见[阶段19记录](阶段19_制作输入与内嵌试跑.md)。

创建自己的工作区用“制作工具 / 创建独立工作区”。枚举/Bean/表头/文本/演员表均为关联资产；在Inspector修改类型后先校验，再同步成员数及数据。嵌套Bean需显式绑定类型，制作控件、六表、C2与Luban共用有界叶成员布局；循环类型与缺失类型会拒绝，避免静默截断。

## 公开合成章节与奖励样例

1. 执行 `Tools / PlotWeave / 迁移样例 / 创建公开合成章节与奖励样例`。
2. 打开 `Assets/PlotWeaveMigration/Stage18_CampaignReference/CampaignReference.unity`，进入Play Mode。
3. 从主线“风之书”开始，体验首次奖励、非连续小节ID与分支；已读小节可重看，奖励不会重复发放。也可打开跳过确认后取消，或确认跳过返回。
4. 切换“日常故事”体验独立进度；主线还展示未来日期和未解锁区域的锁定说明。

默认进度只保存在内存，退出Play后重置。要跨次保存，进入Play前在场景的 `PlotLegacyCampaignHost` 上启用 `persistProgress`，按需设置 `saveFile`（仅文件名，默认 `plotweave-public-reference.json`）；存档位于 `Application.persistentDataPath`。

此入口使用新合成剧情、纯色模板与自绘图片。`Tools / PlotWeave / 本地原布局 / 打开章节与奖励浏览` 等菜单用于本机原布局，需要已有迁移记录与 `Assets/PlotWeaveLocal` 场景；公开合成样例不需要导入这些本地文件。生成菜单遇到已修改的样例资产会停止，避免覆盖用户修改。

## 新补齐的演出与章节

打开`Assets/PlotWeaveMigration/Stage08_Advanced/BranchAndEvents.unity`并Play。点继续后选择森林或村庄；可暂停、自动播放、关闭。资源、音效和特效在PlotPlayerHost上按Key绑定。

打开`Assets/PlotWeaveMigration/Stage10_Chapters/ChapterHost.unity`并Play。主线/日常分别记录进度；完成后返回菜单。正式游戏替换章节后端与导航接口。

事件轨道：新建“PlotWeave / 数据 / 节点事件轨道”，在工作区eventTracks绑定。按节点填写事件、参数与回调，在Inspector校验保存。运行时事件名与参数见阶段08文档。轨道JSON与六份旧表单独交换。

## 表格与Luban

从制作页的“表格互转”进入时，窗口自动绑定当前工作区；独立菜单“制作工具 / Excel与Luban交换”需要手动选择工作区。先处理当前工作副本的未保存修改，再导出六表到新目录；在Excel中编辑这些工作簿后，选择目录、检查导入计划，最后提交带备份的资产更新。导入后制作页重新读取该工作区。不要把历史原型七表格式导入六表工具。

Excel与制作页采用显式导入/导出，不是逐字实时同步。预览未保存输入不会改写Excel或资产；要把这些输入交给表格流程，需在交换前选择保存。选择放弃后交换的是已保存内容。

选择`Assets/PlotWeaveMigration/Stage09_Luban/LubanProfile.asset`执行真实Luban生成。需.NET8和配置中的Luban.dll；新工程已带固定工具，已有游戏可改为自己的工具与运行库。

首次生成会创建C#，等Unity编译后创建`LubanPlayback.unity`场景并Play。报错到Library/PlotWeaveLuban查该次日志；已手改的生成文件不会被覆盖。
