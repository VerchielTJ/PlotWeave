# 阶段08：分支、事件与参考演出

日期：2026-10-28。补齐原Core没有消费的Branch、空动作/表情、未使用的背景SetType和未接入主链的事件回调。最终状态以本阶段Records中的同源码测试、Play Mode与构建记录为准。

## 分支

Core增加WaitingForChoice、Choices和Choose；默认启用，目标0为结束。手动/自动播放都不会替用户选择，暂停期间按钮失效，跳转/关闭使旧按钮回调失效。需要兼容旧Next行为时可显式关闭EnableBranches。

## 调度与制作

`PlotNodeEventTrackAsset`按节点保存事件列表，挂在作者工作区eventTracks。Inspector可编辑、修复GUID、校验保存和导入导出JSON。编译播放快照时合并轨道；未知节点或错误回调拒绝编译。

executionOrder=-1是根事件，按列表顺序；非负值是可引用的回调ID。callbackList按声明顺序深度优先执行。wait/set/signal为内建处理器；项目可注册新处理器返回IPlotOperation，操作完成后才进入回调。单节点最多4096项、4096次执行、回调深度128，单帧同步预算64。循环、缺失ID、重复ID和未知事件明确失败。

变量使用`${key}`在进入节点和执行事件时展开；signal交由宿主订阅。暂停不推进计时；关闭/跳转Dispose操作，迟到资源结果和重入回调不能修改新节点。

## 参考表现

角色：Move/Shake/Jump/FadeIn/FadeOut/Pop/Scale、朝向、命名Animator状态；表情可绑定Sprite，无图片时提供文字气泡。背景：Cut/CrossFade/FadeIn/FadeOut/SlideLeft/SlideRight。音效按片长等待，BGM与循环特效持续至停止/清理，暂停作用于本播放器所属音源、动画和粒子。

移动事件支持Smooth/Capering/Accelerating/Decelerating。原MoveRole映射实际是(ID,方式,位置)，兼容该三参数格式；另可显式使用(ID,速度,方式,位置)。新actor.move使用(ID,位置,时长,方式)。旧游戏RoleName等枚举需接入方映射到演员ID，资源枚举需映射到Key。

示例入口：`Tools / PlotWeave / 迁移样例 / 创建分支与事件演出样例`，场景`Assets/PlotWeaveMigration/Stage08_Advanced/BranchAndEvents.unity`。合成图片、音频和特效均为新建演示内容，参考表现可由项目替换。
