# 公开版首次运行

本说明针对 GitHub 仓库中的公开工程。它使用通用制作工作区与合成示例，不要求拥有原项目数据，也不会恢复本地原布局场景。

## 打开工程

1. 克隆 `https://github.com/VerchielTJ/PlotWeave.git`，或下载仓库 ZIP 并解压。
2. 在 Unity Hub 中添加包含 `Assets`、`Packages`、`ProjectSettings` 的仓库根目录。
3. 使用 **Unity 2022.3.62f3c1** 打开，等待依赖解析和脚本编译。其他 Unity 版本没有验证记录。
4. 若 Unity 提示导入 TMP Essential Resources，使用 `Window / TextMeshPro / Import TMP Essential Resources`；工程已带有示例所用的 TMP 基础资源。

核心包位于 `Packages/com.plotweave.core`。工程依赖由 `Packages/manifest.json` 声明；无需安装 MCP 或其他 AI 插件。

## 录入与保存

执行 `Tools / PlotWeave / 打开剧情编辑器`。入口会选择公开通用工作区、进入 Play Mode 并聚焦 Game 视图。

- 选择节点后编辑当前工作副本；通过“保存”写回作者资产。
- 节点重命名或删除后，需检查其他节点的跳转引用。目前没有自动修复所有引用的保证。
- “表格互转”绑定当前工作区。导出与导入是显式操作，不会在每次键入时自动改写 Excel。
- “试跑当前输入”直接读取尚未保存的当前工作副本，使用独立全屏预览，不会为了试跑先保存作者资产。编辑会话初始化后由 `PlotEditorPlaybackBinding` 绑定预览回调；原布局的页内嵌入方式不随公开内容分发。

退出 Play Mode 或脚本重载时，未保存草稿可保存在 `Library/PlotWeaveRecovery`。草稿恢复存在已记录的基线冲突问题：恢复前先保留当前数据，不将旧草稿直接作为多人协作合并方案。详情见[设计审查](Review/设计审查_2026-10-29.md)。

## 播放合成示例

打开 `Assets/PlotWeaveMigration/Stage18_CampaignReference/CampaignReference.unity` 并进入 Play Mode。该示例以新建 UGUI、文本和纹理展示：

- 主线与日常章节浏览；
- 分支、首次奖励与重看；
- 日期和区域锁；
- 跳过确认与取消。

默认进度存于内存，退出 Play Mode 后重置。若需跨次保存，在场景的 `PlotLegacyCampaignHost` 上启用 `persistProgress`；保存文件位于 `Application.persistentDataPath`，默认文件名为 `plotweave-public-reference.json`。

示例缺失时，可执行 `Tools / PlotWeave / 迁移样例 / 创建公开合成章节与奖励样例`。生成器校验已存在样例的自有文件，手工修改过的生成结果不会被无条件覆盖。

其他入口包括：

- `Stage08_Advanced/BranchAndEvents.unity`：分支、演员表现和事件；
- `Stage10_Chapters/ChapterHost.unity`：章节宿主与返回流程；
- `Stage09_Luban/LubanPlayback.unity`：已生成 Luban 二进制的播放示例。

上述目录均位于 `Assets/PlotWeaveMigration`。已有二进制播放和重新调用外部编译器是两件事。

## 可选：重新生成 Luban 数据

通用录入、作者 Asset 和共享播放核心可以独立使用。仅在需要重新编译 Luban 数据时完成以下准备：

1. 安装 **.NET 8**，确认命令行可以执行 `dotnet --info`。
2. 从 [Luban 官方 v4.10.2 发布页](https://github.com/focus-creative-games/luban/releases/tag/v4.10.2)下载工具。
3. 解压并整理目录，使编译器位于：

   ```text
   Tools/ThirdParty/Luban-4.10.2/Luban/Luban.dll
   ```

4. 在项目的 `PlotLubanProfile` 资产中确认 `dotnetPath`、`compilerDll`、输出目录与程序集名称。也可以将工具放在其他位置，并显式修改 Profile。
5. 从表格/Luban 交换窗口选择该 Profile 执行生成；失败日志位于 `Library/PlotWeaveLuban`。

外部编译器及其 DLL 不随本仓库分发。核心包中的 `Editor/ThirdParty~/LubanRuntime` 是用于示例生成的运行库模板，不等同于完整编译器。
