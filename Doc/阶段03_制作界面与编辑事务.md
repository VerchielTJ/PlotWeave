# 阶段03：制作界面与编辑事务

日期：2026-10-28。状态：本批制作界面与编辑事务已实现并完成限定范围验证；整体迁移继续进行。

## 本批源码对应

- 原 `PlotEditorManager` 的创建、全量/范围读取、重命名、删除及资产路径操作：迁入 `Editor/AuthoringUI/PlotEditorManager.cs`，以工作区实例隔离替代全局固定路径。
- 原节点列表/按钮/创建/当前节点面板：迁入 `Runtime/AuthoringUI/PlotNodeView.cs`、`PlotNodeButton.cs` 与 `PlotAuthoringPanel.cs`。节点按钮仅对可见区域循环复用。
- 原 `NodeRowDataEditor / RowUnit / ParameterEditor / Parameter` 的表头驱动编辑：由新 `ParameterEditor` 根据列类型及Bean参数顺序生成控件；枚举显示label、保存key，未绑定值保留提示，不自动改为第一个值。
- 原 `ParameterList / EvtListParameterEditor`：由独立 `ParameterList` 面板循环绑定可见的Bean行，支持增删、多成员、枚举与普通参数。
- 原 `DiaLogKeyEditor`：恢复节点KEY绑定、按节点生成KEY、对话/常量切换、5种语言、内容修改及KEY移除。修改暂存于副本，不立即改写源资产。
- 原静态事件总线的面板协调职责：通过每个工作区的编辑会话事件协调，避免两个工作区相互串消息。
- 原定制资产Inspector：补入类型/表头引用下拉、动态行与Bean编辑、KEY搜索与分页、通用表动态列编辑、原始数据入口和校验保存。入口为统一资产Editor加类型PropertyDrawer，不按原文件名机械复制多个近似Editor。

## 工作区与入口

`PlotAuthoringProject` 保存表头、对话、常量、演员表、节点目录和ID/对话列配置。

- 新建工作区：`Tools / PlotWeave / 制作工具 / 创建独立工作区`，选择Assets中的父目录。
- 样例：`Assets/PlotWeaveMigration/Stage03_Workspace/`。
- 制作场景：该目录的 `PlotEditorScene.unity`。
- 打开入口：`Tools / PlotWeave / 制作工具 / 打开UGUI制作场景`，进入Play Mode后使用。

该场景是编辑器内的UGUI制作工具，相关面板在UNITY_EDITOR条件下编译，不作为Player游戏界面。预览按钮在共享播放器尚未绑定时禁用，播放接入留到阶段05。

## 保存与生命周期

`PlotEditingSession` 持有节点和文本工作副本；切换节点前选择保存、放弃或取消。保存前先校验，失败保留副本且不写源资产。节点ID通过专门重命名操作修改；普通字段不允许借保存改变资产标识或跨工作区写入。

会话对源资产记录基线，检测其他窗口修改后拒绝静默覆盖。节点及文本数据保存只复制业务字段，不用完整Editor对象JSON覆盖名字、脚本和隐藏标志。

退出Play Mode、重载程序集或关闭编辑器前，可将未保存草稿存入 `Library/PlotWeaveRecovery`；再次运行可点击恢复，仍需检查并主动保存资产。草稿包含数据字段，不依赖上次运行的Unity实例ID。恢复不覆盖尚未处理的当前草稿。

重命名和删除沿用原工具的节点操作范围，不自动猜测并改写其他节点或KEY的引用；界面提示操作者检查入向跳转。

## 当前验证与发现

最终实际EditMode联测77项全部通过：本批会话17项、UGUI面板8项，阶段01为23项、阶段02为14项，原型15项。场景脚本、工作区引用、可见区域复用、暂存保存与放弃、外部修改冲突、草稿恢复、连续创建后保存和资产重导入均已检查。同一源码的Windows x64 Development构建成功；构建场景仍为先前原型，只用于检查Player编译边界。

真实Game View检查发现并修正了窄视图挤压参数列的布局问题。随后发现自建样例的旧内存对象持有初始化默认值，而磁盘文件已保存完整数据：只ImportAsset不能替换该对象，备份后卸载并重载才恢复正确值。已为节点创建增加同步导入和规范实例返回，初始化不创建用户Undo记录，正常保存显式刷新Undo记录，测试销毁前清理其专属Undo对象。新增连续创建后保存首节点、同步重导入一致性回归；不将缓存修复手段包装成对任意用户资产的自动重载。

样式调整中曾误在同一对象添加Image与Text，导致8项界面测试失败；改为独立子对象后重跑77项全部通过。该失败没有作为通过证据使用。
