# 阶段19：制作输入与内嵌试跑

本轮修复原独立制作场景的输入闭环：在同一场景输入节点、参数和文本，立即试跑当前工作副本，再把确认后的数据显式转换为表格。原制作UI的职责和布局来自原系统；当前快照、预览装配与工作区交换连接由本次协作补齐。

## 入口与布局

主菜单为 `Tools / PlotWeave / 打开剧情编辑器`。阶段20起，该入口会自动打开场景、进入Play Mode并显示Game视图；已有可用制作会话时只聚焦Game。工程存在有效的本地原制作场景记录时，优先使用该场景；公开克隆没有 `Assets/PlotWeaveLocal` 等本地内容时，回退通用UGUI制作页。

`Tools / PlotWeave / 本地原布局 / 打开制作界面` 与“制作工具 / 打开UGUI制作场景”仍是静态场景入口，只打开场景并显示一次启动窗口。EditMode尚未初始化输入事务和工具栏；使用主入口或启动窗口按钮进入实际制作。启动、失败清理与多尺寸检查另见[阶段20](阶段20_启动与多尺寸适配.md)，本阶段保留其原23项验收快照。

进入Play Mode后，原UI继续负责节点创建与选择、表头驱动的参数与列表Bean编辑、对话KEY和五语言文本录入。左上 `WindowMask` 内为试跑区，右侧与底部保留制作输入控件。迁移时旧播放器组件只作为布局定位依据，共享播放器在同一预览区域内装配。

对白输入框停靠到预览下方的原预留区域，试跑对白与制作输入分开显示。原 `PosCtrl` 位置标尺移入预览范围，由顶部“站位参考”按钮开关，默认隐藏；其图形不参与射线命中，避免遮住或截获播放控件的点击。

内嵌播放器保留原设计坐标系，按预览区宽高计算统一缩放比例并居中适配；窗口尺寸变化时重新计算。设计尺寸优先使用播放器预制体的有效根尺寸，其次使用原CanvasScaler的参考分辨率。固定坐标的对白、演员与控件一同等比缩放，比例不同时允许留边，不将它们分别拉伸到预览边缘。裁剪继续由原 `WindowMask` 负责。

## 输入、试跑与保存

1. 载入并选择节点，编辑参数或对话文本。更改先进入 `PlotEditingSession` 工作副本。
2. 原布局的起始节点框留空时使用当前节点，也可填入正整数节点ID；点播放后编译最新工作快照。通用制作页使用“试跑当前输入”。
3. 继续输入后点“刷新播放数据”。若预览正在活动，读取最新工作副本并重新试跑当前播放节点，保留自动播放和暂停状态；关闭的预览不会因刷新自行打开。
4. 输入或起点校验失败时保留原活动播放器。输入正确后可再次播放或刷新。
5. 确认后显式保存。原布局提供“保存全部”及参数/对话保存入口；试跑和刷新均不保存资产。切换节点仍按保存、放弃或取消处理未保存修改。

快照包含已有节点，并用当前节点工作副本覆盖对应节点，同时读取工作中的对话与常量文本表。其他未选中节点继续取工作区已保存数据。该机制没有把所有资产转换为可任意编辑的全局内存事务。

## 当前工作区与表格互转

原布局顶部新增“当前工作区表格互转”；通用制作页提供“表格互转”。由制作页打开的交换窗口绑定该页正在使用的 `PlotAuthoringProject`，不需要另猜或另选工作区。独立菜单 `Tools / PlotWeave / 制作工具 / Excel与Luban交换` 仍可使用，但需手动确认工作区。

导出、检查导入及提交导入前，窗口先处理绑定制作页的未保存修改。选择保存后交换包含最新输入的资产；选择放弃后使用已保存内容；取消则中止该次操作。提交成功后制作页重新读取工作区，避免继续显示导入前的副本。

流程为：制作页输入 → 显式保存 → 导出六表 → 表格编辑 → 检查计划 → 提交导入 → 制作页重新读取。也可只在制作页编辑，确认后单向导出。Excel文件不会随输入自动修改，未保存预览也不会改写Excel。六表格式、备份与Luban链保持现有约定，详见[阶段04](阶段04_Excel与Luban交换.md)与[阶段09](阶段09_真实Luban编译与读取.md)。

## 实现落点

- `PlotAuthoringBootstrap.OpenMigratedEditor`：主入口选择原制作场景或通用制作页。
- `PlotLegacyAuthoringHost`：保留原输入控件，提供 `PreviewViewport`、刷新和工作区交换操作；停靠对白输入框并接入站位参考开关。
- `PlotPlaybackCompiler.Compile(PlotEditingSession)`：从当前事务构建无需保存的播放快照。
- `EditorPlotPlayerUI`：同一共享播放核心的内嵌装配、播放和活动刷新；以独立设计坐标根对预览执行等比适配。
- `PlotExcelWindow.OpenFor`：绑定制作工作区及未保存处理、导入后重载回调。
- `PlotEditorManager`：保存当前操作涉及的资产，避免对全部脏资产执行全局保存。

## 尚未解决的边界

本轮不等于全部设计审查问题已关闭。旧草稿缺少可靠的基线冲突合并，恢复前仍需检查共享文本是否已经变化；节点改名/删除与跳转引用完整性的系统处理也仍有开放问题。详见[2026-10-29设计审查](Review/设计审查_2026-10-29.md)。

制作场景运行在Unity编辑器Play Mode；公开合成样例不含本机原剧情及美术。新入口和预览工作流不代表移动真机、生产服务器或公开发布已验收。
